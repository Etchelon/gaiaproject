# SupabaseGenericRepository

A generic repository implementation using the Supabase C# client library, designed to replace the MongoDbGenericRepository in the GaiaProject.

## Overview

This library provides a generic repository pattern implementation for Supabase, allowing for easy database operations with PostgreSQL through Supabase's REST API.

## Features (Planned)

-   Generic repository pattern
-   Support for CRUD operations
-   Query filtering and pagination
-   Real-time subscriptions
-   Connection management
-   Entity mapping

## Dependencies

-   .NET 9.0
-   Supabase C# Client Library

## Usage

This library is currently under development as a replacement for the MongoDB-based repository layer.
